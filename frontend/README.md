# CampusConnect Frontend

The web client for CampusConnect built with React 18, Vite, Tailwind CSS, Lucide React, and Recharts.

## 📦 Tech Stack

- **Framework:** React 18
- **Bundler:** Vite 6 / 8
- **Styling:** Tailwind CSS (Light Theme Design System)
- **Icons:** Lucide React
- **Animations:** Framer Motion
- **Charts:** Recharts
- **Database Client:** Supabase JS v2
- **Notifications:** React Hot Toast

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Copy environment variables
cp .env.example .env

# 3. Start dev server
npm run dev
```

Runs by default on `http://127.0.0.1:5173`.
